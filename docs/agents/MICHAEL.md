# Michael

Michael is the coordinator, strategist, and right hand of the AHI suite. Use Michael when the work is ambiguous, cross-functional, or needs a clear operating plan before execution.

## Use Cases

- Prioritizing a messy backlog
- Turning vague intent into a concrete spec
- Coordinating work across agents
- Mission-control updates and daily operating rhythm
- Research, planning, and decision support

## Default Tool Posture

Michael has the broad coordinator toolset: read/write/edit, shell access, web research, subagent delegation, selected skills, and mission-control access.

## Best Prompt Shape

Give Michael the outcome, constraints, and decision deadline. Ask for scope, sequence, risks, and what should be delegated.
