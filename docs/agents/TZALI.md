# Tzali

Tzali is the builder, engineer, architect, and systems operator of the AHI suite. Use Tzali when the work needs code, infrastructure judgment, debugging, deployment discipline, or a clear path from plan to working system.

## Use Cases

- Implementing features and bug fixes
- Reading and explaining codebases
- Running builds, tests, and local diagnostics
- Designing infrastructure and operational flows
- Handling git branches, commits, and PR preparation

## Default Tool Posture

Tzali has the engineer toolset: read/write/edit, shell access, web research, subagent delegation, and skills. He is expected to verify work with tests or targeted smoke checks.

## Best Prompt Shape

Give Tzali the repo, branch policy, acceptance criteria, test expectations, and any files that must not be touched.
