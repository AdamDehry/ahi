# higgsfield-content-factory Setup

This skill is optional. It ships with the public AHI framework but needs user
configuration before it can run.

Required:

- A Higgsfield account
- The Higgsfield CLI and/or MCP connector configured locally
- Any product, avatar, brand-kit, Soul Character, or Meta Ads account IDs
  supplied by the user at runtime

Do not commit access tokens, connector secrets, account IDs, generated media,
or customer/product-private assets into this public repo.
