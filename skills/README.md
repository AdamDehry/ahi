## How skills arrive and update

Each skill is a folder with a `SKILL.md` whose frontmatter carries `version`, `category`, `last_verified`
and `verified_by`. AHI Setup places this shelf in your AHI folder; when a newer AHI release is
published, Settings → Updates lists the skills that changed and installs them with one button (your own
edits to a skill are kept as a backup in `skills/_backup/`).

Skills never contain credentials, private data, or machine-specific paths. Optional skills that need an
account or a local tool include a `SETUP.md`.
