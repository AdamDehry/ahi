# room-redesign Setup

This skill is optional. It ships with the public AHI framework but needs user
configuration before it can run.

Required:

- A fal.ai account and `FAL_KEY` or `FAL_API_KEY`
- Python with `fal-client` installed
- Project files under `$AHI_HOME/workspaces/interior-design/<project>/<room>/input/`

No API keys or private room photos belong in git.
